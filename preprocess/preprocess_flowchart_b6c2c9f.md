# Header-Based Production Preprocess Flowchart

Scope: current `preprocess/` production flow. The old PDF parsing code is only
used as the upstream OCR/text-layer producer (`glm-ocr` and `pypdf`). The latest
canonical structure is code-generated as `structure_nodes.jsonl` and
`block_nodes.jsonl`; H2-H6 files remain derived compatibility/debug exports.

```mermaid
flowchart TD
  A["raw PDF / HTML / TXT"] --> S0["preprocess.documents<br/>build_document_sources()"]
  Q["question files<br/>doc_ids + domain"] --> S0
  S0 --> S1["processed_data/document_sources.jsonl<br/>allowlisted source manifest"]

  A --> B{"file type"}

  B -->|PDF| P0["preprocess/pdf_to_markdown.py"]
  P0 --> P1["run production parsers:<br/>glm-ocr + pypdf"]
  P1 --> P2["processed_data/pdf_parsed/glm-ocr/{doc_id}.md<br/>combined markdown"]
  P1 --> P3["processed_data/pdf_parsed/_raw/glm-ocr/{doc_id}/glmocr_output/page_XXXX<br/>page md/json + imgs/"]
  P1 --> P4["processed_data/pdf_parsed/pypdf/{doc_id}.md<br/>page-marker text layer"]

  B -->|HTML| H1["preprocess/html_parser.py"]
  H1 --> H2["main text"]

  B -->|TXT| T1["preprocess/txt_parser.py"]
  T1 --> T2["utf-8-sig + newline normalize"]

  S1 --> M0["preprocess/build_parsed_files.py<br/>materialize allowlisted docs"]
  P2 --> M0
  H2 --> M0
  T2 --> M0
  M0 --> M1["processed_data/parsed_files<br/>PDF .md from glm-ocr<br/>HTML/TXT .txt"]

  M1 --> C0{"file suffix"}
  C0 -->|.txt| C1["copy unchanged<br/>shutil.copy2"]
  C0 -->|.md| C2["preprocess/clean_markdown_with_openai.py"]
  C2 --> C3["extract existing markdown heading candidates<br/>line_no + marker + text + neighbors"]
  C3 --> C4["OpenAI Responses API<br/>prompts/clean_markdown_structure.md"]
  C4 --> C5["labels per heading line:<br/>body / h1 / h2 / h3 / h4 / h5 / h6"]
  C5 --> C6["validate labels<br/>all line_no returned<br/>exactly one H1 per doc"]
  C6 --> C7["apply labels to original markdown<br/>body removes # marker<br/>hN gets N # markers"]
  C1 --> C8["processed_data/cleaned_markdown"]
  C7 --> C8

  C8 --> D0["preprocess.documents<br/>build_documents()"]
  S1 --> D0
  D0 --> D1["processed_data/documents.jsonl<br/>doc_id + domain + cleaned title"]

  D1 --> N0["preprocess/build_structure_nodes.py"]
  C8 --> N0
  P4 --> N0
  N0 --> N1["parse cleaned lines<br/>detect markdown headings H1-H6"]
  P4 --> N2["parse pypdf page markers<br/>HTML comment page:N"]
  N1 --> N3["build document -> H2..H6 section tree<br/>stable node_id + parent_id + child_ids"]
  N2 --> N4["match cleaned headings to pypdf text<br/>fill page_start / page_end"]
  N3 --> N5["processed_data/structure_nodes.jsonl<br/>document + section nodes"]
  N4 --> N5

  N5 --> B0["preprocess/build_block_nodes.py"]
  P3 --> B0
  B0 --> B1["split each section direct text<br/>paragraph / table / image blocks"]
  B1 --> B2["merge false PDF/OCR paragraph breaks<br/>only by deterministic rules"]
  B1 --> B3["resolve image_path from raw GLM-OCR page dirs<br/>constrained by section page range"]
  B3 --> B4["if actual image file missing:<br/>image_path = empty string<br/>image_relative_path keeps markdown ref"]
  B2 --> B5["processed_data/block_nodes.jsonl<br/>code-generated paragraph/table/image children"]
  B4 --> B5

  C8 --> H0["preprocess/build_h2_chunks.py --all-levels"]
  P4 --> H0
  H0 --> H3["for each level 2..6<br/>build_heading_chunks(level=N)"]
  H3 --> H4["group by parent heading<br/>direct body text only"]
  H4 --> H5["fill page ranges from pypdf"]
  H5 --> H6["derived exports:<br/>h2_chunks.json ... h6_chunks.json"]
```

Key distinction: `structure_nodes.jsonl` is the canonical document/section tree.
`block_nodes.jsonl` is generated by repository code from that tree and raw parser
artifacts; paragraph/table/image nodes are not hand-authored. Image nodes only
use `image_path` for real files under
`processed_data/pdf_parsed/_raw/glm-ocr/{doc_id}/glmocr_output/page_XXXX/imgs/`.
If the file is absent, `image_path` is empty and the original markdown reference
stays in `image_relative_path`.
